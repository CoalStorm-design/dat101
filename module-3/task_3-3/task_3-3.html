1. What is the difference between invoking and creating a function?

    Creating a function defines what it should do. Invoking (or calling) it runs that code.

  2. Explain the syntax regarding semicolons and code blocks.

    Semicolons terminate statements in JavaScript and help avoid ambiguity caused by automatic semicolon insertion (ASI). Curly braces {} are used to group statements into a code block, and a block itself does not need a semicolon after it.

  3. What happens when we try to store values from a function when it doesn't return any?

    The function call evaluates to undefined, so the variable stores undefined.

  4. How do we separate parameters from each other when creating a function?

    Separate the parameters with commas, for example: function add(a, b) { ... }.

  5. How are parameter names related during function invocation and creation?

    Parameter names are local names inside the function. When the function is called, arguments are assigned to parameters by their position, not by their names.

  6. Why is a parameter undefined when a function call is missing a parameter?

    JavaScript assigns undefined to a parameter when no corresponding argument is provided, unless the parameter has a default value.

  7. What happens when we use recursive functions?

    A recursive function calls itself. Each call runs with its own parameters and waits for the next call to finish. A base case is needed to stop the recursion; otherwise, it can continue until the call stack is exhausted.
