1. Where should you use constants, and where should you use variables? Can they all be constants?

    2. Konstanter brukes når en verdi ikke skal endres, som faste tall, konfigurasjoner eller matematiske konstanter. Variabler brukes når verdien skal kunne oppdateres, for eksempel brukerinput, tellere eller beregnede resultater. Ikke alt kan være en konstant, fordi mange verdier i et program må endres dynamisk.

  2. How do parentheses affect the arithmetic outcome of an expression?

    3. Parenteser endrer rekkefølgen JavaScript evaluerer uttrykk i. Uten parenteser følger JS vanlig matematisk prioritet (multiplikasjon før addisjon). Med parenteser kan vi tvinge JS til å beregne bestemte deler først, noe som kan endre resultatet helt.

  3. How do we limit floating-point numbers to a given number of decimals?

    4. Vi kan begrense flyttall til et bestemt antall desimaler ved å bruke toFixed(n) for tekstformat, eller Math.round(value * 10**n) / 10**n for å beholde tallet som et nummer. Begge metodene brukes for å kontrollere presisjon.

  4. How can we compare two floating-point values to see if they are equal (is 12.199999 the same as 12.2)?

    5. Flyttall kan ha små avrundingsfeil, så vi sammenligner dem ikke direkte med ===. I stedet bruker vi en toleranse, for eksempel: Math.abs(a - b) < 0.0001. Da kan tall som 12.199999 og 12.2 regnes som «like nok».

  5. What do comparison operators return, and how can we check if they are FALSE or TRUE?

    6. Sammenligningsoperatorer returnerer alltid en boolean-verdi: true eller false. Vi kan sjekke dette ved å logge resultatet, eller lagre det i en variabel som: let result = 5 > 3; Da vet vi om uttrykket er sant eller ikke.

  6. How does the Math.random() function work, and what can it be used for?

    7. Math.random() genererer et desimaltall mellom 0 (inklusive) og 1 (eksklusive). Vi kan skalere det opp ved å multiplisere, og runde med Math.floor() eller Math.ceil(). Det brukes i spill, tilfeldige valg, simuleringer og alt som trenger randomisering.

  7. What is modulus (%), and when do we need this operator in mathematical operations?

    8. Modulus (%) gir resten etter en divisjon. Vi bruker det når vi skal finne rester (som sekunder, minutter eller dager), sjekke om tall er partall/oddetall, lage sykliske mønstre eller jobbe med tid og konverteringer. Det er et viktig verktøy når vi bryter ned tall i mindre enheter.
